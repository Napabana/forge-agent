# Bug Fix Workflow

1. Reproduce or inspect the failure before editing.
2. Identify the smallest root cause supported by repository evidence.
3. Make the minimal code change.
4. Run the narrowest relevant test first.
5. Re-run final verification after the last repository change.

Do not claim completion from a successful edit alone.
