# 项目记忆

## 为什么实现

跨任务保留经过验证、可归属到仓库的项目知识，减少重复探索。

## 怎么使用

用 `forgeAgent memory status --repo .` 查看项目记忆，使用 `memory search`、`show` 查询。候选可用 `memory approve` 或 `reject` 管理。

## 怎样实现

项目身份定位记忆根。检索按相关性和上下文预算注入线索。写入先保存候选及来源，完成后结合验收结论决定是否可晋升。隔离成果和外部 verifier 通过各自的证据流程处理。

## 预期效果

将已确认的仓库约束、惯例和经验带给后续任务，保留来源及人工审阅能力。

## 使用边界

记忆是项目级辅助信息。代码现状和独立验收继续作为当前任务的判断依据。
