# 上下文与仓库导航

## 为什么实现

长任务的模型窗口有限。分层上下文让模型优先看到目标、近期观察和相关源码，同时保留可回查的原始证据。

## 怎么使用

直接通过 `run` 或 `chat` 使用仓库导航和上下文预算。通过模型档案配置上下文窗口和输出预算。使用 `forgeAgent runtime --repo . archive SCOPE_ID` 查持久归档。

## 怎样实现

`ConversationHistory` 保存完整消息，包括工具关联与协议字段。`TokenBudget` 计算提示区和生成余量。`RepoMap` 提供仓库符号摘要，持久索引根据仓库状态更新。`TraceableCompaction` 可先裁剪冗长工具输出，再合成带来源的摘要。Canonical History、模型视图与原始归档独立。Chat 按轮保存快照，`/rewind ROUND` 从历史快照建立新会话。

## 预期效果

上下文压力升高时保留近期交互和约束，精确证据仍可通过归档回查。

## 使用边界

摘要可能遗漏语义。旧轮次需要可校验的历史快照。会话回退保留原会话和仓库现状。
