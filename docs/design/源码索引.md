## 3. 状态与测试证据边界

- 单元/确定性集成测试验证代码合同；Failure Harness 是离线故障注入，不是线上成功率。
- `evals/results` 的冻结 report 才能支持对应数字；不得由 README 截图或单次 trace 外推。
- Real-model E2E 只证明该配置、模型和目标仓库的单次链路。
- Benchmark V1 R2 可比较两个冻结 variant，但不能外推为总体 pass@1。
- P2-5 Candidate 的正式结论是 REJECT / not promoted。
