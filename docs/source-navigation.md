# 源码阅读路线

1. 看[整体架构](design/architecture.md)，了解入口、运行时和数据存储。
2. 从[任务执行](design/execution.md)追到[Agent 与工具执行](design/agent-tools.md)，找到一次模型请求和工具调用的完整路径。
3. 按问题查看[上下文与仓库导航](design/context.md)、[长时运行与恢复](design/durable-runtime.md)或[隔离、验收与 GitHub 交付](design/isolation-acceptance.md)。
4. 到[模块与源码索引](design/source-index.md)定位具体目录。
