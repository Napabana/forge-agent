# P0-1 下一轮准备收口

## 本轮目标

为 `PrepareNextTurnResult` 增加显式 Repo Map 刷新指令，将下一 turn 的 callback、Trace、
取消和异常处理集中到单一私有方法，并在 README 固定同步生命周期边界。

## 行为变化

- `PrepareNextTurnResult(refresh_repo_map=True)` 会失效当前仓库摘要，使紧随其后的
  `_build_messages()` 通过现有路径执行全量刷新。
- `Agent.run()` 只在 step 大于 1 时进入 `_prepare_next_turn()`；未配置 callback 时立即
  返回，不改变默认消息。
- callback 前后检查取消，异常仍生成失败 Trace 和 `RunStatus.FAILED`。
- callback 返回的消息仍在下一次模型调用前写入 History。

## 修改文件

- `agent/core.py`：新增刷新字段并提取 `_prepare_next_turn()`，保留原有失败和取消语义。
- `tests/test_prepare_next_turn.py`：新增显式刷新后第二次模型消息可见新文件的契约测试。
- `README.md`：写明第一轮不调用、同步 turn 边界、Observation 时序和终止语义。
- `Forge-Agent-P0-P1-实施计划.md`、`TODO-P0-P1.md`、`AGENTS.md`：同步真实状态。
